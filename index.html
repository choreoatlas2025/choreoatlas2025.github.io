Does your microservice trace follow the expected order flow?

Run a small, reproducible example: compare a recorded order trace with a FlowSpec contract, then inspect the passing order and failed payment reports. The sample traces and contracts are public.

用公开的订单轨迹和 FlowSpec 契约，亲自生成一次通过、一次失败的校验报告，看看跨服务流程哪里偏离预期。

Run the two-trace demo / 运行演示 →

Try it locally

Requires Git, Docker and Make. The demo uses a pinned Community Edition beta image and prerecorded sample traces.

git clone https://github.com/choreoatlas2025/quickstart-demo.git
cd quickstart-demo
make demo

Open reports/successful-order-report.html and reports/failed-payment-report.html. In the current sample, five flow steps pass in the successful trace; the failed payment trace fails the gate. Some input preconditions are skipped because the sample trace lacks the required input fields, so inspect the condition details before applying it to your system.
