# ChoreoAtlas resource landing

A temporary, factual landing page for the organization site. It links only to public resources that were checked as reachable on 2026-09-29. The page deliberately omits the old website's unverified commercial claims, pricing, testimonials, and nonfunctional contact form.

The canonical URL is `https://cq365.eu.org/`. The site shares the domain with the `/docs/` project site, so avoid a root-level `robots.txt` disallow rule.

The GitHub Pages custom domain is `cq365.eu.org`. Cloudflare DNS has the four [GitHub Pages apex A records](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site) in DNS-only mode. Existing Outlook MX, SPF, and autodiscover records are preserved. Verify the domain in organization settings and enforce HTTPS after the certificate is issued.
