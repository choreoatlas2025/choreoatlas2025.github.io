# ChoreoAtlas resource landing

A task-focused landing page for the public CLI quickstart. Its claims refer to the two reproducible sample traces and the reports generated by `make demo`. It does not infer results for real systems from the sample.

`reports/successful-order-report.html` and `reports/failed-payment-report.html` were generated on 2026-09-30 by running `make demo` at `choreoatlas2025/quickstart-demo@99d4787` with `choreoatlas/cli:0.2.0-ce.beta.1`. The HTML files are intentionally committed as public preview assets; regenerate them when the sample or pinned image changes. Some sample input preconditions are `SKIP`.

The canonical URL is `https://cq365.eu.org/`. The site shares the domain with the `/docs/` project site. Root `robots.txt` permits both and the root sitemap index links to the docs sitemap.

The GitHub Pages custom domain is `cq365.eu.org`. Cloudflare DNS has the four [GitHub Pages apex A records](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site) in DNS-only mode. Existing Outlook MX, SPF, and autodiscover records are preserved. Verify the domain in organization settings and enforce HTTPS after the certificate is issued.
